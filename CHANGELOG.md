# Changelog

## [2.0.0] - 2026-03-03

### Added
- Полная совместимость с Moodle 5.1.3
- Hooks API для навигации (замена устаревшего extend_navigation)
- Поле status для работ (submitted, under_review, reviewed, rejected)
- Класс work_manager для централизованного управления работами
- Система уведомлений (студенты получают уведомления о смене статуса)
- Экспорт данных в CSV/Excel/JSON
- Пагинация списка работ
- Фильтрация по типу, статусу, студенту
- Поиск по теме и дисциплине
- AJAX обновление статуса
- Cron задача для очистки старых файлов
- Корпоративный UI/UX 2025
  - Glassmorphism эффекты
  - Тёмная тема
  - CSS переменные
  - Анимации и переходы
- Accessibility (ARIA, keyboard navigation)
- Responsive design (mobile-first)
- Полная локализация (EN/RU)
- Оптимизация SQL-запросов (устранение N+1)
- Внешние ключи и индексы в БД

### Changed
- Обновлён version.php (requires 2025041400)
- Рефакторинг lib.php (удалена устаревшая функция)
- Улучшена валидация форм (минимальная длина, типы файлов)
- Разделены формы студента и преподавателя
- Улучшена обработка ошибок при загрузке файлов

### Fixed
- Исправлены жёстко закодированные строки (теперь get_string)
- Исправлен format_text с указанием контекста
- Исправлена проверка дубликатов (регистронезависимая)

## [1.0.0] - 2026-02-13

### Added
- Базовый функционал загрузки работ
- Просмотр работ студентами
- Просмотр всех работ преподавателями
- Загрузка файлов PDF
- Базовые права доступа
